# Compte et confidentialité

Depuis **Mon compte**, section **Confidentialité**, vous exercez vos droits d’accès, de portabilité et d’effacement.

1. **[Télécharger mes données](./telecharger-mes-donnees)** : obtenir une copie JSON de vos données personnelles.
2. **[Supprimer mon compte](./supprimer-mon-compte)** : effacer définitivement votre compte (avec les précautions nécessaires).

Pour en savoir plus sur le traitement de vos données :

- [Politique de confidentialité](https://efactureconnect.fr/politique-de-confidentialite)
- [Page RGPD](https://efactureconnect.fr/rgpd)
- [Mentions légales](https://efactureconnect.fr/mentions-legales)
