# Télécharger mes données personnelles (RGPD)

Vous disposez d’un droit d’accès et de portabilité. eFactureConnect vous permet d’exporter une copie de vos données de compte.

## Comment faire ?

1. Ouvrez **Mon compte** (menu utilisateur).
2. Allez dans la section **Confidentialité**.
3. Dans la carte **Mes données personnelles**, cliquez sur **Télécharger mes données**.

Le fichier JSON téléchargé s’appelle typiquement `efactureconnect-account-export.json`.

## Que contient l’export ?

L’export porte sur vos **données de compte** : profil, métadonnées d’authentification, sessions, appartenances aux organisations, invitations, et pour les organisations dont vous êtes propriétaire des éléments de configuration (abonnements, environnements, connexions).

Il ne contient **ni secrets** (clés API, etc.) **ni factures clients**.

:::info[Limite de fréquence]

Trop de demandes de téléchargement dans un court délai peuvent être refusées. Réessayez plus tard si besoin.

:::
