# Supprimer mon compte (RGPD)

Vous pouvez exercer votre droit à l’effacement depuis **Mon compte** → **Confidentialité** → zone de danger **Supprimer mon compte**.

## Ce qui se passe

La suppression est **définitive** et irréversible. Votre compte et vos données personnelles sont supprimés. Vous êtes retiré de toutes vos organisations. Les organisations dont vous êtes le **seul membre** sont également supprimées.

## Risques et blocages

Avant de confirmer, assurez-vous d’avoir [exporté vos données](./telecharger-mes-donnees).

La suppression peut être **refusée** dans ces cas :

1. Vous êtes le **seul propriétaire** d’une organisation qui a encore d’autres membres. Promouvez un autre propriétaire (ou retirez les membres restants), puis réessayez. Voir [Gérer les membres](../organisation/gerer-les-membres).
2. Vous êtes le seul propriétaire d’une organisation qui a encore un **abonnement actif**. Résiliez cet abonnement, attendez qu’il soit pleinement terminé, puis réessayez. Voir [Les abonnements](../abonnements/).

{/* Keep admonition outside the list */}

:::warning

Une fois le compte supprimé, vous ne pourrez plus vous reconnecter avec ces identifiants. Les données personnelles associées sont effacées selon les règles décrites dans notre politique de confidentialité.

:::
