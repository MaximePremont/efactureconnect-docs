# Les factures dans eFactureConnect

eFactureConnect synchronise vos factures Stripe, détermine si une **e-facture** ou un **e-rapport** est requis, puis suit le cycle de transmission via SuperPDP.

Le **statut** affiché sur une facture combine deux idées :

1. l’**exigibilité** / l’état de préparation (faut-il traiter ? manque-t-il des infos ?) ;
2. le **workflow** d’envoi une fois le document engagé (en attente d’envoi, en traitement, acceptée, rejetée…).

Pour le détail de chaque libellé et des actions associées, voir [Les statuts des factures](./statuts-des-factures).

Pour réduire les saisies manuelles avant l’envoi, explorez aussi [Automatiser à 100 %](../automatiser/).
