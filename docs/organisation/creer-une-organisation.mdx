# Créer une organisation

L’organisation centralise vos environnements Stripe et la conformité de vos factures. Sans organisation, vous ne pouvez pas configurer eFactureConnect.

## Où la créer ?

**Lors de l’onboarding**, juste après l’inscription, eFactureConnect vous invite à nommer votre organisation (« Créez votre organisation »). C’est l’étape la plus courante.

**Plus tard**, ouvrez le sélecteur d’organisations dans la barre de navigation, puis choisissez **Créer une organisation**. Vous arrivez sur le formulaire « Nouvelle organisation ».

## Ce qu’il faut renseigner

Seul le **nom de l’organisation** est requis (128 caractères maximum). Un nom par défaut peut être proposé à partir de votre e-mail ; vous pouvez le modifier.

En validant, vous devenez automatiquement **propriétaire** de l’organisation, qui devient celle sélectionnée. Vous pouvez ensuite poursuivre la configuration (Stripe, SuperPDP, abonnement) depuis le tableau de bord.

Voir aussi [Gérer les membres](./gerer-les-membres) et le [guide d’installation](../demarrer/).
