# Votre organisation

Une **organisation** est l’espace de travail eFactureConnect qui regroupe ce dont vous avez besoin pour la conformité e-facture : environnements Stripe (bac à sable et production), connexion SuperPDP, membres de l’équipe et abonnement.

Vous choisissez l’organisation active depuis le sélecteur dans la barre de navigation. Un même compte peut appartenir à plusieurs organisations.

## Par où commencer ?

1. **[Créer une organisation](./creer-une-organisation)** : à l’onboarding ou plus tard depuis le sélecteur.
2. **[Gérer les membres](./gerer-les-membres)** : inviter des collègues, définir les rôles Propriétaire et Membre.

L’abonnement est lié à l’organisation (pas à un utilisateur seul). Voir [Les abonnements](../abonnements/). Pour le parcours complet jusqu’à la conformité, voir le [guide d’installation](../demarrer/).
