# Les fonctionnalités à venir

eFactureConnect évolue rapidement. Deux briques majeures sont prévues pour compléter l’émission que vous utilisez déjà aujourd’hui.

## Réception des factures électroniques

Aujourd’hui, eFactureConnect se concentre sur l’**émission** : vos factures Stripe partent en e-facture ou e-rapport via SuperPDP.

La **réception**, c’est l’inverse : recevoir les factures électroniques de vos fournisseurs dans eFactureConnect, grâce au partenariat avec SuperPDP (adresse électronique de réception, annuaire, parcours inbound).

Cette fonctionnalité n’est **pas encore publique** dans l’interface. Une disponibilité plus large est prévue dans le calendrier produit (notamment autour de septembre 2026 pour certains parcours liés à la phase pilote). Vous pouvez déjà rencontrer des choix d’inscription annuaire côté SuperPDP ; la gestion complète dans eFactureConnect suivra. Voir aussi [Se connecter à SuperPDP](../superpdp/).

Sur les [abonnements](../abonnements/), l’accès à la réception est annoncé comme « bientôt » sur Bootstrap, Pro et Business.

## API publique eFactureConnect

Une **API publique** complète permettra d’automatiser encore davantage vos flux (au-delà des metadata Stripe et des leviers déjà documentés).

Cette API est **encore en développement** : elle n’est pas disponible pour le moment. L’accès est prévu sur les plans Pro et Business. En attendant, appuyez-vous sur [Automatiser à 100 %](../automatiser/) (préremplissage, Checkout TVA, metadata).

Nous mettrons cette page à jour dès que ces fonctionnalités seront ouvertes.
