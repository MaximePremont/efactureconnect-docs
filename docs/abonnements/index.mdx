# Les abonnements eFactureConnect

L’abonnement est lié à votre **organisation**. Il est requis pour le mode **Production**, c’est-à-dire pour émettre réellement vers l’administration fiscale et être conforme. Les modes Exemple et Bac à sable restent gratuits.

Seuls les **propriétaires** de l’organisation peuvent souscrire ou modifier un abonnement, depuis la page d’abonnement de l’application.

## Mensuel ou annuel

Vous choisissez un intervalle de facturation :

- **Mensuel** : le prix catalogue ci-dessous, facturé chaque mois.
- **Annuel** : **15 % de réduction** sur l’équivalent de douze mois. Le montant annuel est arrondi à l’euro le plus proche.

| Plan | Mensuel | Annuel (−15 %) |
| --- | --- | --- |
| Bootstrap | 9 € / mois | 92 € / an |
| Pro | 59 € / mois | 602 € / an |
| Business | 199 € / mois | 2 030 € / an |

## Bootstrap

Pour démarrer la conformité e-facturation en douceur.

- 9 € / mois
- 10 factures incluses / mois
- 1,20 € par facture supplémentaire
- Jusqu’à 3 membres
- Accès à la réception (bientôt), voir [À venir](../a-venir/)

## Pro

Le choix idéal pour une activité régulière en production. C’est le plan mis en avant dans l’application.

- 59 € / mois
- 100 factures incluses / mois
- 0,80 € par facture supplémentaire
- Jusqu’à 10 membres
- Accès à la réception (bientôt)
- Accès API (bientôt)

## Business

Pour les volumes importants et les équipes structurées.

- 199 € / mois
- 500 factures incluses / mois
- 0,50 € par facture supplémentaire
- Jusqu’à 50 membres
- Support prioritaire
- Accès à la réception (bientôt)
- Accès API (bientôt)

## Custom

Pour les besoins les plus exigeants : volume élevé, processus spécifiques ou accompagnement sur mesure.

- Volumes et quotas adaptés
- Développement Stripe sur mesure
- Formation de vos équipes
- Accompagnement en facturation électronique

Contact : [support@efactureconnect.fr](mailto:support@efactureconnect.fr).

## Après la souscription

Une fois l’abonnement actif, passez en mode Production et terminez les todos d’installation. Le [guide d’installation](../demarrer/) décrit la suite pas à pas.
