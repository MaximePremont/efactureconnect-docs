# Les modes eFactureConnect

eFactureConnect propose plusieurs **modes** pour explorer le produit, tester vos flux, puis émettre pour de vrai. Vous changez de mode depuis la barre de navigation, via le dialogue **Choisir un mode**.

## Exemple

Le mode **Exemple** vous fait découvrir l’interface gratuitement avec des **données de démonstration non modifiables**. Aucune de vos données n’est utilisée, et rien n’est envoyé nulle part. C’est idéal pour se familiariser sans risque ni configuration.

## Bac à sable

Le mode **Bac à sable** permet de tester gratuitement vos flux de A à Z avec **vos données Stripe**. Les factures partent bien vers la PDP partenaire, mais **pas** vers le gouvernement.

:::warning

Ce mode ne vous rend **pas** conforme. Passez en production dès que vous êtes prêt pour l’envoi réel. Voir [Tester en bac à sable](./tester-bac-a-sable).

:::

## Production

Le mode **Production** est le mode réel et conforme : vos factures sont transmises aux PDP puis au gouvernement. C’est le **seul** mode qui vous permet de respecter vos obligations d’e-facturation.

La production nécessite un [abonnement](../abonnements/) actif. Sans abonnement, le passage en production vous oriente vers la page de souscription.

## Comment changer de mode

1. Ouvrez le sélecteur de mode dans la **barre de navigation** (ou via la bannière de mode en haut du tableau de bord).
2. Choisissez **Exemple**, **Bac à sable** ou **Production**.
3. eFactureConnect bascule immédiatement vers le mode sélectionné.

L’exemple et le bac à sable sont gratuits pour explorer et tester. La production assure l’envoi réel et nécessite un abonnement.

Pour le parcours complet jusqu’à la conformité, voir le [guide d’installation](./).
