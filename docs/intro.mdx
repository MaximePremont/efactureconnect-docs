# Documentation eFactureConnect

Bienvenue sur la documentation officielle d’**eFactureConnect**.

eFactureConnect ajoute la facturation électronique française à Stripe : vous conservez vos parcours de paiement existants, et eFactureConnect fournit la couche de conformité française dont vous avez besoin.

Cette documentation est encore en cours d’écriture. De nouveaux guides et aides arriveront rapidement pour vous accompagner pas à pas.

En revanche, **tout le contenu déjà publié ici est à jour** et maintenu. Vous pouvez vous y fier sans réserve.

Revenez régulièrement : le site s’enrichira au fur et à mesure.
